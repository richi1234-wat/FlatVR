# FlatVR Universal Driver (Vive + Oculus)

In a nutshell, this is a heavily modified fork of [R57Zone's No-VR driver](https://github.com/r57zone/Half-Life-Alyx-novr). 

The goal was to make it as similar to the **Flatplayer** mod for Bonelab, while keeping the original author's cool utility features and adding an experiment for Oculus controller support.

**A note on AI:** I'll be blunt—I used DeepSeek to code this, while I tuned the numbers until they felt right. I'm sure it's got bugs, and I'll fix them up eventually. 

---

## ⌨️ Controls

*(You can change all of these in `FlatVR.ini`)*

### Left Controller
*   **Trigger:** Left Mouse Button
*   **Menu:** Tab
*   **Grip:** Q
*   **System:** 3
*   **Center Trackpad Click:** F
*   **Trackpad:** Arrow Keys

### Right Controller
*   **Trigger:** Right Mouse Button
*   **Menu:** R
*   **Grip:** E
*   **System:** 4
*   **Center Trackpad Click:** V
*   **Trackpad:** Left = B, Right = N, Up = Middle Mouse Button, Down = Spacebar

### Oculus-Specific Bindings
*   **Left Hand:** X = T, Y = Tab
*   **Right Hand:** A = G, B = R

### Hand Movement & Rotation (6DOF)
*   **Left Hand Edit Mode:** X
*   **Right Hand Edit Mode:** C
*   **Move Hand:** Mouse
*   **Rotate Hand (Twist):** Mouse Wheel
*   **Move Hand Horizontally/Vertically:** W, A, S, D *(Note: The screenshot button is in the way by default, you can change this in `FlatVR.ini`)*
*   **Raise/Lower Hand:** 1 (Up), 2 (Down)
*   **Fine Tune / Slow Motion:** H

## 📥 Installation

1. Download the latest `.zip` from the **Releases** tab.
2. Install SteamVR from Steam if you haven't already.
3. Extract the `FlatVR` folder into your SteamVR directory:
   `C:\Program Files (x86)\Steam\steamapps\common\SteamVR\drivers\FlatVR` 
   *(Or wherever you installed SteamVR).*
4. Boot SteamVR. A Headset Mirror should pop up, and you can finally play VR without spending a penny on a physical headset!
