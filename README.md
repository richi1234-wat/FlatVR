Anyways ill write down the controls so you dont have to manually check the Ini:
---
Left Controller:

Trigger = left mouse button
Menu = Tab

Grip = Q

System = 3

Center trackpad click = F

Trackpad = arrow keys.

This is just the Oculus specific stuff, so dont bother reading if u wanna stay on Vive:

X = T

Y = Tab

---

Right Controller:

Trigger = right mouse button

Menu = R

Grip = E

System = 4

Center trackpad click = V

Trackpad = Left=B, Right=N, Up=middle mouse button, down=spacebar.

This is also oculus bindings:

A = G

B = R

Moving the hands?:
---

X = Left hand edit

C = Right hand edit

Flailing the hands (in edit mode) around is obviously moving the mouse,

scrolling rotates the hands in edit mode,

WAZD (Screenshot button is in the way by default, apologies. You could change the control in FlatVR.ini) is to move the hands (in edit mode) around the X (and Z, if i remember the direction?) axis,

1 (up) 2 (down) raises and lowers the hand, and finally, H slows down the hand for precise adjustment. Thats all, i think?

Installation is literally the same as how you install any SteamVR driver:

Download the latest zip from releases

Install SteamVR (directly from Steam), if you dont have it installed

Extract the FlatVR folder into C:\Program Files (x86)\Steam\steamapps\common\SteamVR\drivers\FlatVR, or slightly different if someone installs it somewhere else idk

and Boot SteamVR up. A Headset Mirror should just pop up, and you can finally fuck around without a single penny spent on physical VR!
