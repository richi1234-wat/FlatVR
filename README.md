In a nutshell, this is literally a heavily modified fork of R57Zone's No-VR driver. The modifications in question is literally just making it as similar to this Bonelab code mod Flatplayer (which is still a good mod for no vr), but also having some of the author's cool utility features because they're just that flippin useful, and a little experiment of swapping the VR thingy to an Oculus CV2 (You can tell i used AI to code. Deepseek is kinda good at coding, imo?). I guess you could call it a frankenstein project gone right? Anyways, ill write down the controls so you dont have to manually check the Ini:
Left Controller:
Trigger = left mouse button
Menu = Tab
Grip = Q
System = 3
Center trackpad click = F
Trackpad = arrow keys.
This is just the Oculus specific stuff, so dont bother reading if u wanna stay on Vive:
X = T
Y = Tab

Right Controller:
Trigger = right mouse button
Menu = R
Grip = E
System = 4
Center trackpad click = V
Trackpad = Left=B, Right=N, Up=middle mouse button, down=spacebar.
This is also oculus bindings:
A = G
B = R

Literally moving the hands?:
X = Left hand edit
C = Right hand edit
Flailing the hand around is obviously moving the mouse, scrolling rotates it, and WAZD (Screenshot button is in the way, apologies) is to move the whole hand around, 1 (up) 2 (down) raises and lowers the hand, and finally, H slows down the hand for precise adjustment. Thats all, i think?

Installation is literally the same as how you install any SteamVR driver:
Download the latest zip from releases
Install SteamVR (directly from Steam), if you dont have it installed
Extract the FlatVR folder into C:\Program Files (x86)\Steam\steamapps\common\SteamVR\drivers\FlatVR, or slightly different if someone installs it somewhere else idk
and Boot SteamVR up. A Headset Mirror should just pop up!
